# UI references

Drop screenshots, mockups, sketches or inspiration images in this folder,
then list them below. Claude reads this file and opens the images at every
step: grill, PRD, spec, tickets, planning, implementing and review.

Name images in order: `01-main-window.png`, `02-settings.png`, …
Supported: PNG, JPG, GIF, WebP. For Figma, paste the link (Claude needs the
Figma MCP server connected to open it).

## Screens
| File / link | Screen | Kind | Notes |
|---|---|---|---|
| `01-main-window.png` | Main window | mockup | <what matters: layout? exact colors? just the vibe?> |

**Kind** tells Claude how closely to follow it:
- `exact`: match layout, spacing and colors closely
- `mockup`: match layout and content; styling can differ
- `inspiration`: only the general feel
